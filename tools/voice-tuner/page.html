ParlaSoul · 音色调试台

直接调百炼 Qwen3-TTS 实时合成，链路与线上一致；工具只读，不会改动角色数据。

1 · 音色本体

选一个角色会把它的音色和参数带过来。
换音色比调任何数值都更彻底，声音难听优先从这里换。
可以直接粘贴任意音色 ID，用来试数据库里没有的克隆音色。

2 · 参数

0.5 极慢，1.0 正常，2.0 极快。线上只接受 0.75–1.35。
0–100，默认 50。只改响度，不改音色。线上只接受 20–80。
小于 1 更低沉，大于 1 更尖细。底层是重采样，调大同时会变快变短，所以线上只接受 0.85–1.15。
线上固定下发 English；这里可以换值，用来看不同语种设置下的发音差别。
仅 opus 格式生效，6–510 kbps。

3 · 试听

用角色真实会说的话来试，评价才准。Ctrl/Cmd + Enter 直接播放。
尚未合成。
角色表只存 speech_rate / volume / pitch_rate，超出线上范围的值无法保存。
参数说明
参数作用取值 / 默认怎么用
voice
音色		 说话人的音色本体，决定“这是谁的声音”。 音色 ID，必填 声音难听时优先级最高。换一个音色带来的差别，远大于把语速语调从 0.9 调到 1.1。
speech_rate
语速		 整体语速倍率。 0.5–2.0，默认 1.0 0.95 左右像日常聊天，1.08 以上适合快节奏的怼人台词。低于 0.85 会明显拖沓。
volume
音量		 输出响度，不改变音色和情绪。 0–100，默认 50 调到 60 左右只是变响，不会变“有感情”。别指望靠它救音色。
pitch_rate
语调		 整体音高，实现方式是重采样。 0.5–2.0，默认 1.0 0.9–0.95 让声音更沉稳，1.05 左右更年轻。超过 1.15 会同时加快语速、缩短停顿，听起来失真。
language_type
语种		 告诉模型用哪种语言发音。 Auto / Chinese / English 等；线上固定 English 线上每次合成都显式下发 English。改成 Auto 或 Chinese 只会影响本地试听，不会改变线上行为。
response_format
音频格式		 输出音频的容器格式。 pcm / wav / mp3 / opus，默认 pcm 试听用 mp3 最省事。线上实时通话用 pcm，因为要按帧推流。
sample_rate
采样率		 每秒采样次数，决定音频频响上限。 8000 / 16000 / 24000 / 48000，默认 24000 保持 24000 即可。8000 是电话音，会明显发闷；48000 对人声几乎没有额外收益。
bit_rate
码率		 压缩码率，仅 opus 生效。 6–510 kbps，默认 128 只在格式选 opus 时可调。128 已经够用，调高只减少压缩损失。
mode
交互模式		 服务端自动决定合成时机，还是客户端手动提交。 server_commit / commit，默认 server_commit 只影响推流时机，不影响音色。本工具固定 server_commit，与线上一致，所以没有开开关。
